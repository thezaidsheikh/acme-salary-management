# Salary Management — Incubyte Assessment (ACME)

Web app for an HR Manager to manage salaries for 10,000 employees at ACME
org (currently on Excels), and to answer "how does the org pay people?".

Built branch-per-feature: every feature, change, fix and refactor has its
own branch off `main`, merged with `git merge --no-ff`. See the final
README (branch `docs/readme`) for the full run guide and branch list.
